# Capture frontend screenshots

The build environment used for this implementation does not include Node.js, so screenshots could not be generated here. After installing Node 20 and running `scripts/build_frontend.sh`, start FastAPI and open `http://localhost:8000/`.

Save these three images in this directory:

1. `desktop-light.png` — 1440 × 900, system/light theme, empty welcome state.
2. `desktop-dark.png` — 1440 × 900, dark theme, catalog inspector open.
3. `mobile.png` — 390 × 844, welcome state with the sidebar closed and composer visible.

Use the browser’s built-in screenshot capture or a screenshot utility. Avoid including real customer messages or order identifiers.
